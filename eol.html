Sources. Rails end-of-life dates from the Rails maintenance policy and the supported versions and end-of-support announcements published on rubyonrails.org; Rails release dates from RubyGems. Ruby dates from the Ruby maintenance branches. Verified {{ site.data.eol.verified | date: "%-d %B %Y" }}. Version compatibility from the FastRuby compatibility table. Gem advisories from rubysec/ruby-advisory-db, the database bundler-audit reads, matched the way it matches them. Control references are to PCI DSS v4.0.1, the SOC 2 Trust Services Criteria, 45 CFR Part 164, and ISO/IEC 27001:2022.

This tool reports whether your versions receive vendor security patches, which controls reference that condition, and, if you provide a Gemfile.lock, which published advisories name the gem versions pinned in it. It is not a vulnerability scan: it reads declared version numbers rather than running code, and it cannot see a backported fix, a vendored patch or a compensating control, any of which may already answer a row it reports. It is not a compliance opinion. Whether a given control is met depends on your compensating controls and your assessor.
